Problemi i kako smo ih savladali

🌐 Domen nije radio — vraćao na Loopia Kritično
Problem

Loopia ne dozvoljava upravljanje DNS-om na besplatnom planu. Kupljen domen, ali nije moguće postaviti A records i CNAME ka GitHub Pages.

Rešenje

Cloudflare dodan kao DNS provider. Loopia nameserveri zamijenjeni Cloudflare nameserverima. DNS records postavljeni u Cloudflare panelu.

🔄 GitHub preusmjeravao na Loopia stranicu Kritično
Problem

GitHub Pages custom domain je aktivno preusmjeravao github.io URL direktno na Loopiu dok DNS nije bio riješen.

Rešenje

Privremeno uklonjen custom domain iz GitHub Pages podešavanja dok se DNS nije u potpunosti propagirao. Zatim ponovo dodan.

📜 script.js i styles.css nisu bili na GitHubu Kritično
Problem

Header ostajao transparentan pri skrolovanju. Galerija prikazivala sve slike odjednom. Vizualno haos na live sajtu.

Rešenje

Uploadovana sva 4 fajla: index.html, index-en.html, styles.css, script.js. Ne samo HTML.

📱 SR|EN prelazio u novi red na mobilnom Srednje
Problem

Header switcher za jezik prelazio u novi red na manjim ekranima. CSS grid nije imao dovoljno kolona za sve elemente.

Rešenje

Mobile grid promijenjen na 1fr auto auto (3 kolone). CSS order properti iskorišten za pravilan redoslijed elemenata.

🖼️ Galerija na mobilnom nije swipovala Srednje
Problem

Masonry grid na mobilnom bio neupotreljiv — slike sitne, raspored haotičan, nema intuitivne navigacije.

Rešenje

Na max-width: 640px galeriaja postaje horizontalni flex sa scroll-snap-type: x mandatory. Svaka slika zauzima 80vw.

🗺️ Sitemap odbijen u Search Consoleu Srednje
Problem

Google Search Console vraćao grešku "Invalid sitemap address" pri pokušaju podnošenja sitemapa.

Rešenje

Unesen pun apsolutni URL: https://apartmanmirakul.rs/sitemap.xml umjesto samo sitemap.xml.

📊 Neusklađen broj recenzija na tri mjesta Srednje
Problem

JSON-LD imao reviewCount: "164", og:description "164+", a vidljivi tekst "165 recenzije". Trostruka neusklađenost.

Rešenje

Sve usklađeno na 165 — JSON-LD, og:description i vidljivi tekst u oba HTML fajla.

🏠 Home screen ikona pokazivala pun SEO naslov Srednje
Problem

Pri dodavanju sajta na home screen mobilnog, prikazivao se cijeli <title> tag sa svim ključnim riječima.

Rešenje

manifest.json sa short_name: "Mirakul" i apple-mobile-web-app-title meta tag.

🔗 hreflang tagovi imali relativne URL-ove Manje
Problem

hreflang linkovi koristili href="index.html" i href="index-en.html" — Google to može ignorisati.

Rešenje

Zamijenjeno apsolutnim URL-ovima. Dodan i hreflang="x-default" koji pokazuje na srpsku verziju kao default.

🖋️ SVG namespace koristio https:// umjesto http:// Manje
Problem

Više SVG ikona imalo xmlns="https://www.w3.org/2000/svg" — pogrešan protokol, W3C namespace je uvijek http://.

Rešenje

Replace all u oba HTML fajla. Browseri tolerišu oboje, ali ispravak eliminiše potencijalnu nevalidnost koda.

♿ aria-expanded nije se mijenjao na meniju Manje
Problem

Mobilni hamburger meni nije imao aria-expanded atribut niti ga je JS mijenjao. Screen readeri nisu znali je li meni otvoren.

Rešenje

Dodan aria-expanded="false" i aria-controls="nav-list" na button. JS ažurira vrijednost i aria-label pri svakom klik-u.

🃏 Hero kartica duplirala Booking dugme Manje
Problem

Treća hero kartica vodila na Booking.com — isto kao dugme iznad. Redundantno i bez marketinške vrijednosti.

Rešenje

Zamijenjeno karticom "66 m² komfora / Prostran i udoban za duži boravak" — suptilna poruka koja potiče duže rezervacije.

⚖️ Citati gostiju bez atribucije Bookingu Manje
Problem

Recenzije gostiju prikazane kao da su vlasništvo sajta. Booking recenzije su sadržaj njihove platforme sa pravilima prikaza.

Rešenje

Dodan stilizovan "via Booking.com" link ispod svake recenzije — sitan, italik, prigušen. Klikabilan, pojačava kredibilitet.

💾 GitHub Pages cache — izmjene nisu bile vidljive Manje
Problem

Nakon uploada novih fajlova, live sajt i dalje prikazivao staru verziju. Izgledalo kao da ništa nije promijenjeno.

Rešenje

Ctrl + Shift + R (hard refresh) prisiljava browser da ignoriše cache i učita svježe fajlove sa servera.

Naučene lekcije

Šta pamtimo iz svega ovoga

📦

Upload SVE fajlove

HTML sam po sebi ništa ne radi. CSS i JS moraju biti na serveru da bi sajt funkcionisao.

🌍

DNS treba vremena

Propagacija DNS promjena može trajati i do 48h. Strpljenje je dio procesa.

🔢

Konzistentnost podataka

Isti podatak (broj recenzija) mora biti identičan na svim mjestima — JSON-LD, meta tagovi i vidljivi tekst.

📐

Apsolutni URL-ovi za SEO

Canonical, og:url, og:image i hreflang moraju imati pune https:// URL-ove, ne relativne putanje.

🔄

Hard refresh je tvoj prijatelj

Browser cache je čest krivac za "ovo ne radi". Ctrl+Shift+R rješava 80% konfuzije.

🎯

Svaki element mora imati svrhu

Duplirana dugmad i kartice zbunjuju korisnika. Manje, ali sa jasnom namjerom — uvijek bolje.

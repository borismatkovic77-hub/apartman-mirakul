Kako smo stigli ovde

Koraci koje smo prošli zajedno

🏗️

Struktura i dizajn

HTML, CSS i JavaScript od nule. Hero sekcija sa panoramskom fotografijom, galerija, recenzije, kontakt forma i footer.

🖼️

Optimizacija slika

Sve fotografije konvertovane u WebP format za brže učitavanje. Preload za hero sliku kao LCP element.

🔍

SEO osnove

Canonical tag, og:url i og:image sa apsolutnim URL-ovima, hreflang tagovi sa x-default, favicon, font-display: swap.

🌍

Engleski prijevod

Kompletna EN verzija (index-en.html) sa SR/EN switcherom u headeru — i na mobilnom i na desktopu.

🚀

GitHub Pages deployment

Besplatan hosting na GitHub Pages. Domen apartmanmirakul.rs kupljen na Loopia, DNS prebačen na Cloudflare.

🔒

HTTPS i custom domen

Cloudflare DNS records (A + CNAME), GitHub Pages custom domain, Enforce HTTPS uključen.

📱

Mobilni UX

Galerija postala swipe carousel na mobilnom. Kartice sakrivene na malim ekranima. Dugmad pomjerena pri dno hero sekcije.

📋

Forma i detalji

Ime i prezime spojeni u jedno polje. Email ili telefon u jedno polje. Airbnb uklonjen. Manifest.json za home screen ikonu.

🗺️

Google Search Console

DNS verifikacija vlasništva. Sitemap.xml sa hreflang alternativama podnesen na indeksiranje.

📊

Google Analytics GA4

Measurement ID G-V2HG1VDQZF dodan u oba HTML fajla. Praćenje posjeta aktivno.

✨

Finalni polishing

Recenzije atribuirane "via Booking.com". SVG namespace ispravljen. aria-expanded za navigaciju. Hero kartica sa porukom o dužem boravku.
